# 设计语言与参考（v1.0）

> 配套：`01-产品设计文档-PRD.md`、`02-开发规范-SPEC.md`、`web/index.html`（可运行原型）
> 目标：不做一个"又是一个 ChatGPT 皮肤"的界面，而是有自己调性的面试教练。

---

## 一、调研：值得抄的对话界面（产品 / 公司）

### 1. 对话类 AI 产品

| 产品 | 最值得抄的一点 | 我们怎么用 |
|---|---|---|
| **Anthropic Claude** | **Artifacts 分栏**：对话与产出物分两栏，长输出不淹没对话流；calm 视觉层级不抢内容 | 右侧常驻「本场概览 + 当前打分卡」面板（原型里做成回答旁的浮动卡 + 侧栏概览），报告页独立成页 |
| **OpenAI ChatGPT** | **克制**：干净线程、工具调用内联卡片按需展开、模型选择器不打断流程 | 输入区只有一个输入框 + 两个按钮，不堆功能 |
| **Perplexity** | **引用即信任**：每个结论带来源 pill | 打分卡的每一个维度都可展开到"这题在考什么（hints）"——**给分必须给依据** |
| **Cursor** | **diff 即主界面**：把"AI 要改什么"摊开给用户 | 报告页的逐题明细可展开看原文回答，分数与原文一一对应 |
| **Granola**（会议 AI） | 实时转写 + 人工可编辑，人机共同持有一份文档 | 语音转写**回填输入框、用户确认后再发**，不替用户发送 |
| **v0 / Lovable** | 生成预览本身就是消息；可见的构建步骤 | 面试官"正在组织下一题"用打字指示器 + 进度点，过程可见 |

### 2. 设计系统（学调性，不学皮）

| 公司 | 调性 | 可提取的零件 |
|---|---|---|
| **Anthropic** | 编辑感：定制衬线、奶油白底、散文优先组件、安静的按钮、几乎看不见的动效 | 暖白画布 `#FAF9F7`、衬线用于标题与大数字、按钮一律安静 |
| **Notion** | 温暖极简：近黑文字（非纯黑）、1px 细边框、超柔阴影、8px 栅格 | 正文色 `#1F1E1C`（不用纯黑）、`1px` hairline 边框、阴影仅 `0 1px 2px / 4%` |
| **Linear** | 精准：Inter + 负字间距、半透明边框、状态指示器、微动效 | 6px 状态点（题目进度）、紧凑圆角、过渡 120–150ms |
| **Vercel** | 工程感：Geist、纯黑白 + 单一强调色、4px 微圆角 | 全站只用**一个**强调色（靛蓝 `#4B5BD6`），其余靠灰阶分层 |
| **Stripe** | 信任感：纯净白底、保守圆角、金融级克制 | 数字用等宽 tabular-nums，分数对齐不掉位 |
| **Lovable** | 消费级温暖：柔和粉彩、大圆角 | 打分卡圆角 12–14px，不锐利，降低"被评判"的压迫感 |

## 二、本项目设计语言（已落地到 web/index.html）

**一句话：奶油白底 + 衬线标题 + 单一靛蓝强调 + hairline 边框 + 克制动效。**
"专业但不冷，评分但不审判。"

### Token

| 类别 | 值 | 说明 |
|---|---|---|
| 画布 | `#FAF9F7`（暖白） | 不用纯白，长时间看不刺眼（Anthropic） |
| 表面 | `#FFFFFF` / 次级 `#F5F3EF` | 卡片与侧栏两级即可，不超过三层 |
| 边框 | `#E7E3DC`（hairline 1px） | 主要分隔手段，比阴影更干净（Notion） |
| 文字 | `#1F1E1C` / 次级 `#6B6760` / 弱 `#9A958C` | 近黑，三级足够 |
| 强调 | `#4B5BD6`（靛蓝），软底 `#EEEDFE` | **全站唯一强调色** |
| 语义 | 优 `#0F6E56` / 中 `#854F0B` / 待改进 `#A32D2D` | 只在评分徽章出现，不做大面积色块 |
| 字体 | 标题衬线 `Songti SC / Noto Serif SC`；正文 `-apple-system / PingFang SC` | 中英混排都稳 |
| 圆角 | 16 / 12 / 8 | 容器 16，卡片 12，控件 8 |
| 阴影 | `0 1px 2px rgba(31,30,28,.04), 0 4px 16px rgba(31,30,28,.03)` | 一层极淡，不做多层光晕 |
| 动效 | 出现 `rise .28s`（Y+6px → 0）、进度条 `.5s cubic-bezier(.2,.7,.3,1)` | 只用于"新信息到达"，不用于装饰 |

### 布局

- **左栏 236px**：品牌 + 新建 + 历史场次（可回看）。常驻，不隐藏。
- **中栏**：Setup / Session / Report 三态切换。对话区最大宽度 760px（阅读舒适区）。
- **回答旁的打分卡（250px）**：本产品的记忆点。Claude 的 artifact 思路搬到"每题一个产出物"。

### 组件规范

| 组件 | 规范 |
|---|---|
| 面试官消息 | **不用气泡**。小标签（面试官 + 第 N 题）+ 衬线 16.5px 正文，左对齐，留白呼吸 |
| 用户回答 | 白色卡片，`14px 14px 4px 14px` 不对称圆角指向右侧，最大宽度 88% |
| 打分卡 | 标题「JEV 实时评分」+ 档位徽章；5 条 4px 细进度条；底部置信度。`low_confidence` 时整体 62% 透明度 |
| 骨架屏 | 评分到达前显示 4 条脉冲条，**不阻塞对话**（异步模块的可视化承诺） |
| 进度点 | 顶部 6px 圆点，已完成实心、当前放大 1.5× 带光环 |
| 输入区 | 16px 圆角大卡片，自动增高（最高 180px），右下方麦克风 + 发送；聚焦时 3px 靛蓝柔光环 |
| 报告页 | 52px 衬线总分 + 雷达图（SVG 手绘） + 三条建议卡 + 逐题明细表（可展开原文） |

### 已规避的"AI 味"土味

- ❌ 渐变、霓虹、玻璃拟态、深色发光背景
- ❌ emoji 当图标（全部用 1.5px 线性 SVG）
- ❌ 大圆角胶囊 + 高饱和紫渐变按钮（典型的 AI 生成模板）
- ❌ 到处都是阴影和色块

## 三、下一轮可优化（v1.1 候选）

1. **深色模式**（Linear 式极简深色：近黑底 + 靛蓝），token 已按 CSS 变量组织，半天可加。
2. **打分卡 hover 展开依据**：显示"这题在考什么（hints）"+ 该维度被扣分的一句话理由（Perplexity 的引用逻辑）。
3. **报告页时间轴**：把逐题明细做成纵向时间轴，分数条随滚动出现。
4. **快捷键**：`Cmd+Enter` 发送、`Cmd+K` 新建面试（ChatGPT / Linear 惯例）。
5. **移动端**：单栏 + 打分卡折叠为可展开条（Claude 的面板切换思路）。
6. **空状态**：Setup 页的引导文案与示例卡片（降低冷启动焦虑）。
